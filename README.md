# ai-judge-relax-01 — The Tortoise at Dusk

A slow sensory scene: an old tortoise crosses a garden path at dusk, pausing on warm flagstones as the light thins, passing a blackbird and reaching the rosemary bush, where he tucks himself under the lowest branch and sleeps with the whole afternoon still in his shell.

Run with `python3 main.py`; it writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
